# TextTruth AI — AI vs Human Text Detector

A full-stack web application that detects whether text was written by a human or generated by AI.

## Tech Stack
- **Frontend**: React 18 + Tailwind CSS (standalone HTML, no build step)
- **Backend**: Python Flask
- **Model**: `roberta-base-openai-detector` (HuggingFace) with heuristic fallback

## Project Structure
```
texttruth-ai/
├── frontend/
│   └── index.html          # Complete React app (open directly in browser)
├── backend/
│   ├── app.py              # Flask API
│   └── requirements.txt    # Python dependencies
├── sample_texts.txt        # Test inputs
└── README.md
```

## Quick Start

### Step 1 — Backend Setup

```bash
cd backend

# Create virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # Linux/Mac
venv\Scripts\activate           # Windows

# Install dependencies
pip install -r requirements.txt

# Run the server
python app.py
```

The backend starts at **http://localhost:5000**

> **Note**: First run downloads the `roberta-base-openai-detector` model (~500MB).
> If the model can't load (no GPU/memory), the app automatically falls back to a
> fast heuristic detector.

### Step 2 — Frontend

Just open `frontend/index.html` in your browser — no build step needed!

## API Reference

### `POST /predict`

**Request:**
```json
{ "text": "Your text to analyze..." }
```

**Response:**
```json
{
  "label": "AI Generated",
  "confidence": 87.3,
  "ai_score": 87.3,
  "explanation": "High confidence this text was AI-generated. Heuristic analysis detected: ...",
  "model_used": "roberta-base-openai-detector"
}
```

### `GET /health`
Returns server status and which model is loaded.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "Cannot reach backend" | Make sure `python app.py` is running |
| CORS error | Backend already has CORS enabled for all origins |
| Model download fails | App uses heuristic fallback automatically |
| Out of memory | Heuristic mode is used — no GPU required |
